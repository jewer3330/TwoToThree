# 打印流程姿态与尺寸稳定性修复计划

## 背景

打印工作台的分件预览出现主体偏向左上、裁切和视觉倾斜；当前产出的 STL/3MF 还会直接继承源模型坐标与单位，存在模型悬空、偏离打印床、尺寸被误当成毫米以及多部件导出范围错误的风险。

## 远程同步基线

- 上游：`https://github.com/hanzhicao82-stack/TwoToThree.git`
- 跟踪名：`caohanzhi`
- `caohanzhi/main`：`b87232e`
- `caohanzhi/agent/blender-auto-refinement-v1`：`a859ef1`
- 比较结果：两个远程分支均已是当前 `printworld-all` 的祖先，没有待合并提交；本地分别领先 97 和 91 个提交。
- 内部远程 `origin/printworld-all` 已同步到 `5261ca6`，该提交同样已包含在当前分支。

## 根因

1. Blender 预览相机只有硬编码欧拉角，没有朝向包围盒中心，也没有根据部件尺寸设置正交取景范围。
2. 分件前没有把对象世界变换烘焙到网格，也没有执行整件统一缩放、XY 居中和 Z=0 落台。
3. UI 把 Blender 原始坐标直接标为毫米，3MF 也声明为毫米，源 GLB 单位不一致时会得到错误打印尺寸。
4. STL 导出只改变选择状态，但未显式要求“仅导出选中对象”，多对象模型可能生成重复部件。

## 实施方案

1. 在分件脚本中对所有网格使用同一个整件变换：
   - 烘焙对象世界变换；
   - 计算整件世界包围盒；
   - 按目标高度等比缩放到毫米；
   - XY 中心移动到原点；
   - 最低点移动到 `Z=0`；
   - 保持各部件之间的相对位置不变。
2. 默认目标高度采用 120 mm，并允许打印任务在 10–500 mm 范围内配置。
3. STL 导出显式限制为当前选中部件。
4. 缩略图改用正交相机，通过 `track_quat` 始终朝向部件中心，并按投影尺寸自动留边。
5. 拆分报告记录目标高度、缩放系数、归一化前后包围盒及单位，便于追溯。

## 验收标准

- 缩略图主体居中、完整，不再贴边或被裁切。
- 报告中整件最低 Z 坐标接近 0，XY 中心接近原点。
- 默认整件高度接近 120 mm，UI 显示值与 3MF 毫米坐标一致。
- 多部件 STL 各自只包含对应部件，同时保留共同装配坐标。
- Python 测试、前端测试和生产构建全部通过。
- 开发服健康检查通过，并使用真实打印任务完成上传、分件、预览和 3MF 导出冒烟测试。

## 回滚方式

本次修改集中在打印分件脚本、打印 API 参数、前端目标高度输入和相关测试；若开发服真实模型验证异常，可整体回滚该修复提交，不迁移或破坏已有项目数据库。
