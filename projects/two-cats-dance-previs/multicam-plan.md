# 双猫舞蹈多机位预演 v2

## 测试目标

验证同一段舞蹈由多个机位覆盖时，角色身份、动作相位、空间方向和剪辑连续性是否成立。所有机位沿用 v1 的 640×352、24 FPS、33 帧、Wan 2.2 TI2V 5B 基线。

本轮不是把 9 个镜头顺次播放，而是生成 3 组动作覆盖；每组 3 个机位，剪辑时在同一动作段内择优切换。

## 不可变规则

- 黑猫始终在画面左侧，橘猫始终在画面右侧；除非镜头明确标为反打，禁止跨越 180° 轴线。
- 每组 A/B/C 三机位使用同一个动作描述、相同 33 帧长度和相同节拍起点。
- 角色设定、服装、餐厅、钨丝灯、青绿色幕布、棋盘地面与 v1 一致。
- 每个镜头前 5 帧保持动作准备态，主要动作发生在第 6–28 帧，第 29–33 帧落回稳定姿态，给剪辑留把手。
- 机位运动与角色复杂动作不同时叠加。本轮所有机位固定，只测试切镜，不测试运镜。

## 三组机位覆盖

| 动作组 | 镜头 | 机位 | 画面任务 | 剪辑用途 |
|---|---|---|---|---|
| A 左右踏步 | A01 | 正面双人全景 | 建立空间、完整看腿 | 主镜头/安全镜头 |
| A 左右踏步 | A02 | 左前 30° 双人中全景 | 黑猫略近、保留双脚 | 第一次节拍切换 |
| A 左右踏步 | A03 | 右侧低机位腿脚近景 | 突出点地和脚跟 | 动作强调镜头 |
| B 上身律动 | B01 | 正面双人中景 | 肩臂同步关系 | 主镜头/安全镜头 |
| B 上身律动 | B02 | 右前 30° 中近景 | 橘猫略近、两张脸可见 | 角色表演镜头 |
| B 上身律动 | B03 | 侧面双人轮廓中景 | 观察躯干扭转方向 | 节奏变化镜头 |
| C 收尾定格 | C01 | 正面双人全景 | 两步收拢后共同定格 | 结尾主镜头 |
| C 收尾定格 | C02 | 左前 30° 双人中景 | 表情与上身姿态 | 定格前切入 |
| C 收尾定格 | C03 | 棋盘地面低机位广角 | 脚掌落定、身体入画 | 最后重拍强调 |

## 推荐剪辑测试版

时间线总长仍为 99 帧：

| 时间 | 使用素材 | 切点意图 |
|---|---|---|
| 0–10 帧 | A01 | 先交代双猫与轴线 |
| 11–21 帧 | A02 | 在左脚落地后切角度 |
| 22–32 帧 | A03 | 右脚落地特写结束 A 组 |
| 33–43 帧 | B01 | 回到正面建立新动作 |
| 44–54 帧 | B02 | 肩膀换向时切近 |
| 55–65 帧 | B03 | 以侧面轮廓加强扭转 |
| 66–76 帧 | C01 | 全景进入收尾 |
| 77–87 帧 | C02 | 定格前看角色表情 |
| 88–98 帧 | C03 | 脚掌落定后结束 |

若动作相位不一致，退回三段安全剪辑：A01 → B01 → C01，不强行做跳切。

## 生成顺序与止损点

1. 先做 A01、A02、A03。只有三机位都保持左右关系且动作相位可匹配，才继续 B/C 组。
2. 再做 B01、B02、B03。若侧面 B03 身份漂移，只淘汰 B03，不重做整组。
3. 最后做 C01、C02、C03。优先确保 C01 可单独承担结尾。
4. 本地 Wan 每个镜头最多两次尝试；第二次仍不通过的镜头进入云端候选，不继续消耗本地时间。

## 云端升级规则

- Seedance：角色表演、面部稳定和收尾定格失败的 B02/C02。
- Kling：脚步相位、肢体动作或已有视频编辑失败的 A03/C03。
- 其余镜头优先继续留在本地 Wan；只有进入最终剪辑且明显拉低观感时才升级。
