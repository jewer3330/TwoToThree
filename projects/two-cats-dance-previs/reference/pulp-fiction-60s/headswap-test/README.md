# 参考帧双猫换头测试

## 映射

- 白衬衫舞者 → 黑色短毛猫头。
- 黑西装舞者 → 橘色虎斑猫头。
- 只替换头部和颈部衔接；保留原身体、动作、手势、服装、镜头、灯光和背景。

## 最终测试帧

| 时间 | 文件 | 结论 |
|---|---|---|
| 10 秒 | `final/headswap-wide-10s.png` | 双人全景通过；头部尺度、身份映射和身体动作关系可读 |
| 36 秒 | `final/headswap-black-close-36s.png` | 黑猫近景通过；二次编辑将首轮偏大的头部缩小约 18% |
| 55 秒 | `final/headswap-orange-close-55s.png` | 橘猫近景通过；手指保持在人脸前景，遮挡关系可用 |

## 使用的编辑提示结构

三张图均使用内置 imagegen 的 `precise-object-edit` 工作流：

1. 指定视频抽帧为唯一构图、身体、动作、服装、灯光和背景来源。
2. 指定现有双猫关键帧为猫头身份参考。
3. 白衬衫只换黑猫头，黑西装只换橘猫头。
4. 锁定手、手指、四肢、衣服、背景人物和画幅，只允许修改头部与颈部接缝。
5. 近景首轮头部偏大，二次提示只缩小猫头约 18%，其余内容保持不变。

## 对视频换头的判断

静帧方法可行，但不能直接把这三张图逐帧扩展成一分钟视频。视频阶段还需要：

- 逐镜头处理，而不是整段一次处理。
- 猫头身份参考和头部尺度锁定。
- 人脸/头部跟踪、遮挡保护和逐帧闪烁检查。
- 先用 2–3 秒全景镜头做连续性测试，再处理快速近景和手遮脸镜头。
