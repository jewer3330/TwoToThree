# 本地 ComfyUI 整体镜头还原测试

## 测试目标

优先验证参考片 10–13 秒的整体镜头，而非猫头细节：

- 超宽舞台构图。
- 略低、固定的双人全景机位。
- 两位舞者面对面并保持间距。
- 观众、舞台和空间纵深保持稳定。
- 小幅屈膝、step-tap 和上身律动连续发生。

## 本地条件

ComfyUI 当前安装 Wan 2.2 TI2V 5B、SD 1.5 Inpainting、MediaPipe 和 SAM3 节点，但没有 Wan Animate/VACE 对应模型权重，也没有 ReActor/InsightFace 换脸节点。

因此 v1 使用换头后的 10 秒全景静帧作为 Wan TI2V 首帧，生成 73 帧、640×272、24 FPS 的连续镜头。它用于验证构图和镜头语言，不能被视为原动作的逐帧复刻。

## 输出

- `reference-shot-10s-13s.mp4`：参考原片 10–13 秒。
- `local-wan-shot-recreation-v1.mp4`：本地 Wan 镜头还原测试。
- `comparison-reference-vs-local-v1.mp4`：左侧参考、右侧本地结果，使用原片音频。

## 质检结论

| 项目 | 结论 | 说明 |
|---|---|---|
| 构图 | 通过 | 超宽低机位、舞台中心和观众背景成立 |
| 双人站位 | 通过 | 两人面对面且保持分离，没有换位 |
| 镜头稳定 | 通过 | 三秒内固定镜头，无明显推拉摇移 |
| 空间稳定 | 通过 | 舞台和观众未发生整体崩塌 |
| 动作方向 | 部分通过 | 有膝盖律动和前臂动作，但幅度小于参考片 |
| 动作相位 | 不评为复刻 | TI2V 没有读取原视频姿态，只参考了首帧与文字提示 |
| 猫头细节 | 非优先 | 只要求黑/橘身份大致可读 |

## 下一步

若继续本地路线，最有价值的升级是补齐 Wan Animate 或 VACE 模型权重，把原 3 秒视频真正作为 pose/control video；继续增加 TI2V 提示词只能改善动作倾向，无法获得逐帧动作还原。
